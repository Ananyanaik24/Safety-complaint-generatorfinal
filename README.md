# Safety Complaint Generator

An NLP-based multilingual safety complaint generation system supporting Hindi and English.

## Features

- Hindi and English complaint input
- Hindi text preprocessing
- English text preprocessing
- Hindi to English translation
- Complaint category prediction
- TF-IDF feature extraction
- Logistic Regression classification
- Entity extraction
- Hindi safety advice
- Formal English complaint generation
- MongoDB complaint storage

## Project Workflow

User
→ Web Application
→ Text Preprocessing
→ Translation
→ Complaint Classification
→ Entity Extraction
→ Safety Advice
→ Formal Complaint Generation
→ MongoDB
→ Results
